# Карточка товара Teaboom.ru — «Ананасовый улун»

Тестовое задание: вёрстка карточки товара интернет-магазина.

## Что реализовано

- Изображение, название, категория, описание
- Выбор фасовки: 100 / 500 / 1000 / 5000 г
- При переключении меняются цена, старая цена, артикул
- Кнопка «В корзину» с hover-состоянием
- Адаптив: desktop (1440), tablet (768), mobile (375)

## Стек

- HTML5
- CSS3 / SCSS
- JavaScript

## Запуск

1. Скачай проект.
2. Открой `index.html` в браузере.

Сборка не требуется — стили уже подключены через `style.css`.
